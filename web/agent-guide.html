在 ChatGPT 插件中添加自定义 MCP，地址填写 https://timemate.cc/mcp，选择 OAuth，登录并授权自己的 TimeMate 账户。然后让 Dot 关注 TimeMate 的变更。通知入口由平台自动登记。

当前尚未上架插件目录。自定义接入及事件任务需要你的账号支持，首次使用需完成实际连接测试。

Grok Bot

  1. 在 TimeMate 设置 → 个人 Agent，选择 Grok Bot，生成独立连接凭证。
  2. 把配置说明发给 Bot，凭证仅填入其安全凭证输入框。
  3. 让 Bot 创建接收 TimeMate 通知的 Webhook Routine，将 POST to 和 key 填回 TimeMate。
  4. 点击“发送测试”。通知送达后，Bot 读取最新状态并调用回执工具，页面会显示“已收到反馈回执”。

Routine 被触发会使用你的 Grok Bot 额度。通知送达不代表任务已经完成。

Muse

可让 Muse 创建自定义连接器，使用 TimeMate MCP 地址和独立凭证。当前仅验证主动查询与传入的接口，尚未确认 Meta 的主动唤醒入口，不承诺实时反馈。

你的控制权

连接只访问你的账户。默认可读取邮件和事项、传入邮件、获取变更；修改事项需要额外授权。邮箱授权码与模型 API Key 不会共享。断开连接即撤销后续访问；Agent 已接收的内容需在对应平台管理。
