隐私说明

适用于 TimeMate 当前版本 · 更新日期：2026 年 10 月 19 日

邮件助手是云端服务，不是仅在你的电脑本地处理邮件的软件。请在注册和连接邮箱前了解以下信息。

我们处理哪些信息

我们保存登录邮箱与密码哈希、邮箱和模型连接设置，以及导入的邮件内容、分析结果、日程和操作状态。邮箱客户端授权码与 API Key 加密保存，网站登录密码不以原文保存。

注册和密码找回时，我们通过 Resend 邮件服务向你填写的邮箱发送一次性验证码（该服务会处理收件邮箱和验证码邮件内容），用于确认邮箱访问权。验证码限时有效，并以摘要形式保存。

邮件会发送到哪里

相应邮箱的邮件先按你设置的规则转发到你选择的接收邮箱。邮件助手通过加密连接读取该邮箱，按你配置的来源邮箱规则导入邮件，数据保存在当前 Railway 服务器的持久化存储中。分析时，邮件标题、发件人、日期与正文会发送给你选择的模型服务商；请求中文翻译时，相应邮件内容也会发送给该服务商。邮箱客户端授权码不作为模型分析内容发送，API Key 用于向对应服务商认证。服务商如何保存和处理请求，以其政策为准。

Google 邮箱数据

通过 Google 连接时，TimeMate 请求 Gmail 只读权限（gmail.readonly），用于导入收件箱邮件和后续同步；该授权不能发送、修改或删除 Gmail 邮件。同步后的邮件保存在你的 TimeMate 账号中，用于邮件查看、分类、摘要和事项提取。

TimeMate 不出售 Google 用户数据，不将其用于广告或训练通用 AI 模型。你使用 AI 分析邮件时，邮件内容会发送给你自行配置的 AI 服务商，用于提供该项功能；服务商的处理规则以其政策为准。TimeMate 对 Google API 数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

使用 AI 对话上传图片时，图片会发送给你已连接的模型服务商用于识别；为便于在同一对话中继续核对，当前一批图片会加密缓存于你的账号中，7 天内可用于后续识别；过期后不再读取，并在访问时清理。新图片会替换当前批次的缓存，删除对话会删除对应缓存。对话文字、资料摘录和识别出的事项会保存。浏览器会重新编码图片以去除 EXIF 等附带元数据。服务商对请求的保存规则以其政策为准。“自动添加”会将识别且通过验证的事项加入重要事项；“逐项确认”支持选择事项后批量添加；缺少具体日期的事项需先确认，未注明钟点的日程可经你确认按日期记录。删除对话不会删除已加入的重要事项。

保护措施与访问边界

网站使用 HTTPS，按登录账号隔离数据，保存的凭证不通过设置接口返回原值。邮件正文、摘要、邮箱地址和日程目前没有应用层加密。拥有服务器访问权限的管理员可以读取这些数据；拥有服务器权限及加密密钥的管理员也可以解密凭证。凭证加密不代表管理员无法访问。

个人 Agent 连接

只有在你授权后，外部个人 Agent 才能读取你的邮件和事项、传入邮件或获取变更；修改事项需要相应权限。变更通知仅发送记录编号与操作类型，Agent 可以依据授权读取对应内容。邮箱授权码和模型 API Key 不向 Agent 开放。通知密钥在服务器加密保存，连接令牌以摘要形式保存。你可在设置中断开连接，停止后续访问与通知；此前已发送到外部平台的信息，需在该平台管理。通知投递记录保留 30 天；账户内变更记录随账户删除。

日历与外部内容

日历订阅链接可以读取你已确认加入的日程，请勿公开或转发该链接。原邮件的外部图片默认不加载；主动加载图片或打开链接时，会连接外部网站，对方可能获取网络地址等访问记录。

保存、停用与删除

当前版本没有自动到期清除规则，保存的数据会持续保留，直到被清理。关闭自动检查可停止定时检查，但不会删除已保存的数据。

你可以在“个人账户 → 删除账号”中输入当前密码，自助删除账号。操作会清除该账号在 TimeMate 中的邮箱、凭证、邮件、分析结果、对话、日程和订阅链接，并使登录失效。Google 授权会一并尝试撤销；如果撤销请求失败，页面会提示你到 Google 账号设置中手动移除 TimeMate。删除账号不会代替你在邮箱或 AI 服务商处撤销其他独立授权。

账号删除会从 TimeMate 当前运行数据中移除相关账号数据。任何由部署平台或管理员另行创建的备份，须按其保留策略单独清理；在备份清理完成前，不能承诺存储介质上的历史副本已立即物理擦除。

内测反馈

请向 TimeMate 管理员反馈问题。不要在反馈截图、群聊或公开代码仓库中发送授权码、API Key、密码或日历订阅链接；邮件截图请遮住不必要的私人内容。
