## 应用用途

TimeMate 帮助大学生集中查看、整理和理解学校邮件。用户可直接连接自己的 Google 邮箱；TimeMate 读取收件箱邮件以显示、搜索、分类和同步邮件，并为用户提供摘要、待办事项和截止日期提取。用户也可以在 AI 对话中询问其邮件内容。

## 请求的 Gmail 权限

请求 `https://www.googleapis.com/auth/gmail.readonly`，仅用于读取当前用户的邮件和邮件元数据。

更窄的 `gmail.metadata` 不能读取正文，而摘要、翻译、事项提取和邮件阅读都依赖正文，因此不足以提供已实现的核心功能。TimeMate 不发送、修改或删除 Gmail 邮件，也不请求 `mail.google.com` 全邮箱权限。

## 数据流和使用说明

用户授权后，TimeMate 服务端通过 Gmail API 读取收件箱邮件。访问令牌、刷新令牌和授权流程临时数据使用服务端主密钥加密保存；邮件、摘要、用户设置和日程按 TimeMate 账号隔离后保存在部署数据盘。管理员在技术上可以访问邮件正文；凭证加密不构成端到端加密。

用户启用 AI 分析或主动在 AI 对话中提问时，相关邮件内容会发送给用户自行配置的 AI 服务商，用于生成该功能所需的结果。服务商如何保存或处理请求，取决于对应服务商的规则。TimeMate 不出售 Google 用户数据，不将其用于广告或训练通用 AI 模型。TimeMate 对 Google API 数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

## 用户控制和删除

用户可在个人账户菜单中删除 TimeMate 账号。删除会清除该账号在当前运行数据中的凭证、邮件、分析结果、对话、事项和日历订阅链接，并使登录失效。服务会尝试撤销 Google 授权；如果撤销请求失败，页面会指导用户到 Google 账号设置中手动移除 TimeMate。由运营者或托管平台另行创建的备份需按其保留策略单独清理。
