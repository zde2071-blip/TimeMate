首次使用引导

按顺序完成前三步，就可以开始自动分析邮件。日历可以之后再连接。

1. 学校邮件自动转发到 QQ 邮箱

登录学校的 Outlook 网页版，进入“设置 → 邮件 → 规则 → 添加新规则”。给规则起名（例如“转发到 QQ”），将条件设为“应用于所有邮件”（或不添加条件），操作选择“转发到”，填入完整 QQ 邮箱地址并保存。这样以后收到的学校邮件会自动转发，不需要逐封操作。最后发一封测试邮件，确认 QQ 邮箱收到了。

如果学校不允许向外部邮箱自动转发，请联系学校 IT。

Outlook 官方自动转发规则说明 ↗打开 Outlook 网页版 ↗

完成标记保存在当前浏览器；邮件转发规则由 Outlook 管理。

2. 开启 QQ 邮箱 IMAP 并连接

QQ 邮箱授权码是给邮件助手使用的专用登录凭证，和 QQ 密码不同。登录 QQ 邮箱网页版，进入“设置 → 账户”，开启 IMAP/SMTP 服务并按页面提示验证、生成授权码。

回到下方邮箱设置，填写完整 QQ 邮箱地址、授权码和学校邮箱地址，先点“测试连接”，成功后保存。

QQ 邮箱官方授权码说明 ↗打开 QQ 邮箱 ↗
3. 创建 API Key 并连接 AI

在你选择的模型服务商开放平台创建 API Key，再回到下方选择同一家服务商、填写 Key、获取模型列表并选择文本模型，测试通过后保存。API Key 是调用模型的凭证，请勿发给他人；服务商可能按使用量收费。

4. 连接日历可稍后设置

邮件和 AI 设置完成后，再连接 Apple 日历或 Outlook 日历。只有你确认加入的日程才会同步。

日程安排和截止事项有什么区别？

有明确开始和结束时间的安排，放在“日程安排”；需要在某个日期前完成、但没有固定时段的任务，放在“截止事项”。由你决定是否加入。
